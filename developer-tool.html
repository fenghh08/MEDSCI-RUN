Contribute Content

Fill in the fields below — no code needed. This generates ready-to-paste code in the exact format the Runner Game uses. When you're done, copy or download your batch and send it to Eason.

How this works

  1. Type your name below (so Eason knows who submitted what).
  2. Pick a tab: New Item (a study guide entry), New Question, or New Theme (a whole new subject area).
  3. Fill in the fields. A code preview updates live on the right — you don't need to understand it, just check the fields look right.
  4. Click "Add to batch". Repeat for as many items/questions as you want to contribute.
  5. When you're done, "Copy entire batch" or "Download as .txt" and send it to Eason (with any image/icon files you mentioned, named exactly as shown).
Used only to credit you in the batch you send — doesn't affect any IDs or filenames.
